🔗 How to set up Gist Sync
You only need to do this once. Your token is stored locally on this device only.
Step 1 — Create a GitHub account
If you don't have one, sign up free at github.com. No special plan needed.
Step 2 — Generate a Personal Access Token
  1. Go to github.com/settings/tokens/new
  2. Under Note, type something like Ritual Habit Tracker
  3. Set Expiration to No expiration (or 1 year)
  4. Under Select scopes, tick only gist ✓
  5. Scroll down and click Generate token
  6. Copy the token that appears — it starts with ghp_
  7. ⚠ GitHub only shows it once — copy it now!
Step 3 — Paste the token into Ritual
In Settings → Gist Sync, paste your token into the GitHub Token field.
Step 4 — Leave Gist ID blank (first time)
Leave the Gist ID field empty. When you click ⬆ Backup now or ⬆ Push now for the first time, Ritual will automatically create a new private Gist and fill in the ID for you.
Step 5 — Sync to another device
On your second device:
  1. Enter the same GitHub Token
  2. Enter the Gist ID that was saved after your first push (copy it from your first device's Settings)
  3. Click ⬇ Restore now to pull everything down
Metrics sync vs Full backup
⬆ Push now — sends only daily totals (water, habit %, stuff count) for use by WellStat.
⬆ Backup now — sends your entire app: habits, sub-tasks, check-ins, icons, all logs, and settings.
